## Overview

The work is organized as a four-week externship sequence:

- `Week 1` — Amazon review scraping and introductory NumPy and pandas exercises.
- `Week 2` — descriptive statistics and Matplotlib and Seaborn visualizations.
- `Week 3` — NLTK and TextBlob exercises and additional deliverables.
- `Week 4 (Final Capstone)` — the final capstone notebook.

The notebooks analyze consumer-review data and develop findings for consumer insights. The repository does not include a dataset manifest at its root; individual notebooks document their own inputs.

## Notebook reference

The repository's analysis format is compatible with [Google Colab notebooks](https://colab.research.google.com/notebooks/data_table.ipynb); use the individual notebooks' documented inputs when reproducing the work.

## Usage

Open the notebooks from the relevant week in Jupyter and follow each notebook's documented input and setup requirements.
